Privacidade

Este site não usa cookies, não tem formulários e não recolhe dados pessoais.

Para mostrar a última versão, o navegador pergunta à API pública do GitHub pelas versões do projeto. As fontes vêm do Google Fonts e os ícones do unpkg. Esses serviços podem registar o pedido como qualquer site.

O jogo grava os saves e o log só no seu computador e não envia nada para a internet.
