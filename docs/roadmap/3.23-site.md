# Marco 3.23 — Site do jogo (GitHub Pages)

Uma página única que apresenta o NextCM, mostra o jogo com prints reais e leva ao download do
beta. Fica em `https://victorb999.github.io/NextCm/`.

**Pronto quando:** o site está no ar pelo Pages, com prints reais do jogo, as funcionalidades que já
existem e o botão de download a apontar sempre para o instalador da Release mais recente.

## Decisões

- **Onde:** pasta `site/` na raiz do repositório (a `docs/` já guarda o roadmap e os vídeos).
  Publicação por um GitHub Action (`.github/workflows/pages.yml`) que envia a `site/` para o Pages
  a cada push que mexa nela. Sem build: HTML e CSS à mão, um pouco de JS.
- **Download:** o botão aponta para `releases/latest`. Um pouco de JS pergunta à API do GitHub
  pelo asset `*-setup.exe` da última Release (pre-releases incluídas) e mostra o nome da versão
  e o tamanho. Se a API falhar, o link continua a ir para a página das Releases.
- **Prints:** só capturas reais do jogo (1280×720, em PNG/WebP), tiradas pela ponte de dev ou pelo
  app, guardadas em `site/prints/`. Nada de mockups desenhados.
- **Números:** só os que existem de facto (por exemplo "época 2025/26", as ligas vivas do
  3.6/3.7). Nada de contadores inventados, depoimentos ou "milhares de jogadores".
- **Nome:** "NextCM, inspirado no Championship Manager 01/02". Sem logótipos nem arte da SI/Eidos.
  No rodapé: projeto de fãs, sem fins comerciais.
- **Créditos à Coalizão CM:** uma secção própria, não só uma linha no rodapé (ver Secções). O mesmo
  crédito vai para o `README.md`, o `docs/BETA.md` e as notas das Releases.

## Secções

1. **Topo:** nome, uma frase ("O CM 01/02 com a base de dados 2025/26"), selo "beta", botão
   **Baixar para Windows** (versão e tamanho) e um print grande do jogo numa moldura de janela.
2. **Prints:** galeria com legendas curtas (dia de jogo ao vivo, Tácticas, Plantel, perfil do
   jogador, mercado, Classificação). Clicar abre em tamanho real.
3. **Funcionalidades:** grupos curtos tirados dos marcos feitos: dia de jogo (motor por lances,
   relato, palestras), o clube (plantel, tácticas, treino, reservas), mercado e olheiros, direcção
   e empregos, mundo (ligas, taças, Libertadores, Liga dos Campeões, selecções), editor de saves.
4. **Sobre:** o que é o projeto, a ideia (o CM 01/02 com a velocidade e a densidade de então, num
   mundo de hoje) e a tecnologia (Rust, Tauri, React) numa linha.
5. **Beta:** requisitos (Windows 10/11, 1280×720), aviso do SmartScreen, link para o guia
   (`docs/BETA.md`) e para as Issues.
6. **Créditos:** a **[Coalizão CM](https://www.coalizaocm.com.br/)**, "o maior acervo nacional de
   CM 01-02". A base 2025/26 e o tema vêm do Update Coalizão (patch CLZ), feito pela equipe
   Coalizão. Texto curto e um link bem visível para o site deles, e um convite a conhecer o
   Update, as databases e os tutoriais de lá. Sem logótipo deles, a não ser que a equipe autorize
   (eles não têm página de créditos nem regras de citação). Também ficam nos créditos os
   parceiros que valer a pena citar (champman0102.net).
7. **Rodapé:** GitHub, Releases, aviso de projeto de fãs e "base de dados: Update Coalizão".

## Design (proposta)

```yaml
Design Read:
  artefacto: landing page de uma página
  público: quem jogou CM 01/02 e procura o "seu" CM com plantéis de hoje
  linguagem visual: a do próprio jogo (tema Coalizão do CM 01/02), em formato web
  modo: greenfield, mas presa à marca do jogo
  variação visual: 4   # secções regulares; o protagonista são os prints
  movimento: 2         # só hover e foco; o jogo não tem animações
  densidade: 6         # mais densa que uma landing normal, como o CM
  dependência de assets: 9  # sem prints reais não há site
  fidelidade à marca: 9
```

- **Cores** (as do `game/src/index.css`): fundo `#161616` com a textura do `.cm-backdrop`, coluna
  `#45526a`, roxo dos botões e da barra de rolagem `#5b1fa6` / `#8b5bd6`, verde dos diálogos do
  jogo nos cabeçalhos das secções, texto branco e cinza `#999`.
- **Tipografia:** títulos em Trebuchet MS (a `--cm-title-font` do jogo), texto em Tahoma/Verdana.
  Corpo a 16px na web (o jogo usa 12px; numa página isso fica pequeno demais).
- **Forma:** cabeçalhos de secção como as faixas e os diálogos verdes do CM; botões roxos com os
  cantos levemente arredondados, como no app. Sem cards flutuantes nem gradientes da moda.
- **Movimento:** nenhum além de hover/foco nos botões e nos prints. `prefers-reduced-motion`
  respeitado.
- **Telemóvel:** uma coluna, prints a toda a largura, botão de download avisa que é só para
  Windows.
